# Lampa Shikimori

Окремий інформаційний плагін для **Lampa 3.x**. Додає пункт **«Shikimori»** у головне меню, показує сезонний каталог Shikimori, фільтри, дозавантаження і детальну картку. Назва не конфліктує зі штатним пунктом Lampa **«Аніме»**. Плагін не містить джерел відтворення.

Версия плагина: **1.5.1**. В фильтре периодов добавлен отдельный пункт «За всё время», снимающий ограничения по годам и сезонам перед применением фильтров.

## Можливості

- стартова добірка поточного сезону;
- рідні картки, сітка, фокус і навігація Lampa 3.x;
- фільтри сезону/року, статусу, типу, жанру і сортування;
- п’ять останніх років із окремими сезонами, далі — десятиліття від 2020-х до 1910-х;
- дозавантаження по 24 картки;
- постер, рейтинг, тип, статус, серії, тривалість, жанри, студії й опис;
- кеш у `localStorage` на 15 хвилин, один запит на сторінку, обробка HTTP 429;
- українські підписи та стани завантаження/помилки/порожньої відповіді.

## Встановлення за URL

Опублікуйте файл `outputs/lampa-shikimori.js` через HTTPS (GitHub Pages, власний сервер або інший статичний хостинг). У Lampa відкрийте **Налаштування → Розширення → Додати плагін**, вставте повний HTTPS URL до JS-файлу й перезапустіть Lampa.

Приклад після публікації:

```text
https://example.org/lampa-shikimori.js
```

`file://` і локальний шлях на телевізорі зазвичай не працюють; Lampa має отримати файл за HTTP(S).

## Локальна перевірка

Потрібен Node.js 18+.

```powershell
npm run check
```

Для ручної перевірки віддайте каталог через будь-який статичний HTTPS/HTTP сервер, додайте URL `outputs/lampa-shikimori.js` у тестову Lampa 3.x і перевірте меню, фільтри, скрол, Enter/Back та сторінку деталей.

## CORS і опційний proxy

Плагін спочатку звертається безпосередньо до:

- `POST https://shikimori.io/api/graphql`
- `GET https://shikimori.io/api/genres`
- REST fallback: `GET https://shikimori.io/api/animes`

На момент перевірки `shikimori.one` перенаправляє API-виклики на `shikimori.io`; браузерний `fetch` переходить автоматично, а опційний proxy одразу використовує канонічний API-хост, щоб не втратити тіло POST під час redirect.

Робота прямого запиту залежить від CORS/мережевої політики конкретної збірки Lampa, WebView, DNS і регіону. Якщо запити блокуються, запустіть мінімальний allow-list proxy:

```powershell
npm run proxy
```

За замовчуванням він слухає `http://localhost:8787` і проксіює **лише** `/api/graphql` та `/api/genres`. Для телевізора розгорніть цей файл на доступному HTTPS-хості та задайте його базовий URL в консолі Lampa:

```js
localStorage.setItem('lampa_shikimori_v1:proxy', 'https://proxy.example.org')
```

Щоб повернути прямі запити:

```js
localStorage.removeItem('lampa_shikimori_v1:proxy')
```

У production обов'язково задайте `ALLOWED_ORIGIN` доменом вашої Lampa, а не `*`.

## Контракти та сумісність

Плагін орієнтується на Lampa 3.x (`Manifest.app_digital >= 300`) і використовує актуальні `Lampa.Maker`, `Component`, `Activity`, `Menu`, `Select`, `Scroll`, `Controller` та `Head`. Дані беруться з офіційного GraphQL `animes` Shikimori; жанри — з офіційного REST `/api/genres`. Максимальний серверний ліміт GraphQL — 50, плагін навмисно використовує 24.

Вихідні еталони:

- https://github.com/yumata/lampa-source
- https://github.com/shikimori/shikimori
- https://shikimori.one/api/doc

## Відомі обмеження

- назви й описи приходять у тих мовах, які віддає Shikimori; окремого українського поля API не має;
- детальна сторінка не використовує стандартний `full`, бо він виконує запити через вбудовані джерела Lampa (TMDB/CUB), а Shikimori є окремим джерелом;
- точна CORS-поведінка відрізняється між браузером, Android/WebView, webOS і Tizen; для цього proxy залишений явною опцією;
- GraphQL не повертає загальну кількість результатів, тому кінець каталогу визначається за неповною сторінкою.
