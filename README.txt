================================================================================
ПЛАГИН SHIKIMORI ДЛЯ МЕДИАПЛЕЕРА LAMPA (shikimori_lampa.js)
================================================================================

1. ОБЩАЯ ИНФОРМАЦИЯ
--------------------------------------------------------------------------------
Название плагина : Shikimori Catalog & Anime Card Plugin for Lampa
Файл плагина     : shikimori_lampa.js
Версия           : 2.4.0
Дата разработки  : 28 сентября 2026 г.
Целевая система  : Медиаплеер Lampa (https://lampa.mx и совместимые клиенты)
Источник данных  : Официальный API Shikimori (https://shikimori.io)

2. НАЗНАЧЕНИЕ ПЛАГИНА
--------------------------------------------------------------------------------
Плагин является современной заменой устаревшего и более не работающего плагина
Shikimori (ранее размещавшегося на lampame.github.io/main/shikimori.js).
Он добавляет в главное боковое меню Lampa самостоятельный раздел «Shikimori»,
интегрирует вкладку «Shikimori» в глобальный поиск Lampa и позволяет:
- просматривать актуальный каталог аниме (онгоинги, популярное, топ рейтинга,
  новинки сезона, ожидаемые анонсы, полнометражные фильмы, OVA/ONA/спешлы,
  расписание выхода серий);
- открывать полноценные карточки аниме непосредственно внутри интерфейса Lampa
  без перехода во внешний браузер;
- переходить по связанным произведениям (сиквелы, приквелы, спин-оффы, OVA,
  фильмы) и хронологии всей франшизы;
- выполнять точное сопоставление выбранного аниме с базой TMDB/Lampa для
  перехода к просмотру через установленные онлайн-балансеры и торрент-парсеры.

3. СОВМЕСТИМОСТЬ И ТРЕБОВАНИЯ
--------------------------------------------------------------------------------
- Версии Lampa   : Lampa 1.8.x — 2.x+ (актуальная ветка yumata/lampa-source).
- Платформы      : Android TV / Google TV (APK), Samsung Tizen, LG webOS,
                   Apple TV / iOS, Windows / macOS / Linux (Desktop), Web-браузеры.
- Управление     : Полная поддержка пульта ДУ (D-Pad: Вверх/Вниз/Влево/Вправо,
                   OK/Enter, Back/Return), клавиатуры, мыши и сенсорных экранов.

                   штатные механизмы Lampa и встроенный CSS).

4. ИСПОЛЬЗУЕМЫЕ API И ДОМЕНЫ SHIKIMORI
--------------------------------------------------------------------------------
В феврале 2026 года проект Shikimori сменил основной домен с `shikimori.one`
на `shikimori.io` (старый домен возвращает HTTP 301 Moved Permanently, что
привело к поломке старых плагинов при POST-запросах и загрузке постеров).

Плагин использует гибридную схему запросов к `https://shikimori.io` (с резервным
автопереключением на `https://shikimori.one`):
1) Основной протокол — Shikimori GraphQL API (`POST https://shikimori.io/api/graphql`):
   - Запрос каталога и поиска: `animes(page, limit, order, status, kind, genre, search, censored)`
   - Запрос полной карточки: `animes(ids: "<id>", limit: 1)` (включает `poster { originalUrl mainUrl previewUrl }`,
     `genres`, `studios`, `scoresStats`, `statusesStats`, `related`, `screenshots`, `videos`, `chronology`).
   - Преимущество GraphQL: отдаёт актуальные прямые ссылки на постеры в формате
     WebP/JPEG (`/uploads/poster/animes/...`), тогда как устаревший REST API v1
     для многих тайтлов (например, Death Note ID 1535) возвращает заглушку
     `/assets/globals/missing_original.jpg`.Кроме того, GraphQL позволяет получить
     карточку, связанные релизы и хронологию за 1 HTTP-запрос вместо 4–5.
2) Резервный протокол и специальные маршруты — Shikimori REST API v1:
   - `GET https://shikimori.io/api/animes` — резервный метод каталога/поиска;
   - `GET https://shikimori.io/api/animes/:id` и `/api/animes/:id/related` — резервный метод карточки;
   - `GET https://shikimori.io/api/animes/:id/similar` — список похожих аниме;
   - `GET https://shikimori.io/api/calendar` — календарь выхода серий онгоингов.

5. АВТОРИЗАЦИЯ И ЛИМИТЫ ЗАПРОСОВ (RATE LIMITS)
--------------------------------------------------------------------------------
- Авторизация OAuth2 для чтения каталога, карточек, хронологии, расписания и
  поиска НЕ требуется. Все используемые запросы являются публичными.
- Официальные лимиты Shikimori API: до 5 запросов в секунду (5 RPS) и до
  90 запросов в минуту (90 RPM). При превышении сервер возвращает HTTP 429.
- В плагине реализованы:
  * очередь запросов с минимальным интервалом (`minIntervalMs: 260 мс`, т.е. не более ~3.8 RPS);
  * дедупликация одновременных одинаковых запросов (`inflightRequests`);
  * кэширование ответов в оперативной памяти (`TTL 30 минут` для каталога и карточек,
    `15 минут` для календаря).

6. УСТАНОВКА И ПОДКЛЮЧЕНИЕ В LAMPA
--------------------------------------------------------------------------------
Способ 1 (Через интерфейс Lampa):
1. Разместите файл `shikimori_lampa.js` на любом статическом хостинге с поддержкой
   HTTPS (GitHub Pages, Cloudflare Pages, Vercel, собственный сервер).
2. Откройте Lampa -> перейдите в «Настройки» (иконка шестерёнки вверху) ->
   «Расширения» (или «Плагины») -> «Добавить плагин».
3. Введите URL вашего файла, например:
   https://example.com/shikimori_lampa.js
4. Перезапустите Lampa. В левом главном меню появится пункт «Shikimori».

Способ 2 (Локальное подключение / Консоль разработчика):
В браузерной версии `https://lampa.mx` код из `shikimori_lampa.js` можно выполнить
через консоль разработчика (DevTools) или подключить через пользовательский скрипт.

Настройка зеркала (необязательно):
По умолчанию плагин обращается к `https://shikimori.io`. При необходимости можно
задать домен вручную в хранилище Lampa:
`Lampa.Storage.set('shikimori_domain', 'https://shikimori.io')`

7. ДОСТУПНЫЕ ФУНКЦИИ ПЛАГИНА
--------------------------------------------------------------------------------
- Пункт главного меню «Shikimori» (`Lampa.Menu.addButton` + резервный DOM-метод).
- Главная витрина (`shikimori_main`):
  * Популярные онгоинги сезона;
  * Популярные аниме всех времён;
  * Высокий рейтинг Shikimori;
  * Новинки и свежие релизы;
  * Ожидаемые анонсы;
  * Полнометражные аниме-фильмы;
  * OVA / ONA и специальные выпуски.
- Панель быстрых действий: Поиск, Онгоинги, Топ рейтинга, Популярное, Анонсы,
  Фильмы, Жанры (20 основных жанров и демографий), Календарь релизов.
- Каталог разделов (`shikimori_category`):
  * бесконечная пагинация при прокрутке вниз (`page: 1..N`);
  * переключение сортировки (по популярности, по рейтингу, по дате выхода, по алфавиту).

8. ПОИСК АНИМЕ
--------------------------------------------------------------------------------
Поиск работает в двух режимах:
1) Через кнопку «Поиск аниме» непосредственно внутри раздела Shikimori (`Lampa.Input.edit`).
2) Через стандартный глобальный поиск Lampa (иконка лупы в шапке Lampa) — плагин
   регистрирует собственный источник `Shikimori` через `Lampa.Search.addSource`.
   Поддерживается ввод названий на русском, английском, японском (ромадзи и кандзи),
   а также поиск по альтернативным названиям (синонимам).

9. КАРТОЧКА АНИМЕ (`shikimori_full`)
--------------------------------------------------------------------------------
При выборе любого аниме открывается полноценная карточка внутри Lampa, содержащая:
- постер высокого разрешения и фоновую подложку (`Lampa.Background`);
- русское, оригинальное (ромадзи), английское, японское, лицензионное и альтернативные названия;
- рейтинг Shikimori и общее число голосов (рассчитывается из `scoresStats`);
- тип релиза (TV Сериал, Фильм, OVA, ONA, Спешл, Клип), статус (Вышло, Онгоинг, Анонс);
- год выхода, даты начала и окончания показа, возрастной рейтинг (G, PG, PG-13, R-17, R+);
- количество вышедших и общих эпизодов, длительность серии, список студий;
- интерактивные теги жанров (нажатие открывает каталог выбранного жанра);
- очищенное от BBCode-тегов описание на русском языке;
- список эпизодов с индикацией статуса выхода и быстрым переходом к просмотру;
- связанные произведения (Сиквелы, Приквелы, Побочные истории, Спин-оффы, OVA, Фильмы);
- полную хронологию франшизы и кнопку подбора похожих аниме (`/api/animes/:id/similar`).

10. ИНТЕГРАЦИЯ С КОНТЕНТОМ LAMPA (ПРОСМОТР)
--------------------------------------------------------------------------------
Поскольку Shikimori является энциклопедическим каталогом и не хранит видеопотоки,
для запуска просмотра в карточке реализована кнопка «▶ Смотреть в Lampa» (`matchAndWatchInLampa`):
1. Плагин обращается к штатному поиску `Lampa.Api.search` (TMDB) по русскому и
   оригинальному названию аниме.
2. Каждый найденный кандидат оценивается алгоритмом верификации по совпадению:
   - названия (русского, оригинального, английского);
   - года выхода (`aired_on` ± 1 год);
   - типа контента (`tv` для сериалов/OVA/ONA, `movie` для полнометражных фильмов);
   - признака анимации (TMDB genre ID `16`).
3. Пользователю открывается диалог `Lampa.Select` с отсортированными по точности
   совпадениями (с указанием года, типа и рейтинга TMDB) и пунктом резервного
   глобального поиска по всем источникам Lampa. При выборе открывается штатная
   карточка Lampa (`component: 'full', source: 'tmdb'`), где доступны все
   установленные у пользователя онлайн-балансеры и торренты.

11. СТРУКТУРА ФАЙЛА `shikimori_lampa.js`
--------------------------------------------------------------------------------
Весь код инкапсулирован в IIFE `(function () { 'use strict'; ... })()`:
- `PLUGIN_MANIFEST`, `CONFIG`, словари локализации типов/статусов/рейтингов;
- `escapeHtml`, `cleanShikimoriText`, `resolveImageUrl` — санитизация и обработка данных;
- `getCache`, `setCache`, `scheduleTask`, `httpRequest` — сетевой уровень, кэш и защита от 429;
- `normalizeAnimeItem` — унификация ответов GraphQL и REST API v1 в единый формат;
- `ShikimoriAPI` (`fetchCatalog`, `fetchAnimeFull`, `fetchSimilar`, `fetchCalendar`);
- `injectPluginStyles` — встроенные адаптивные стили для TV/Desktop/Mobile;
- `matchAndWatchInLampa` — безопасное сопоставление карточки Shikimori с TMDB/Lampa;
- `ShikimoriMainComponent`, `ShikimoriCategoryComponent`, `ShikimoriFullComponent` — компоненты Lampa;
- `registerGlobalSearchSource`, `addMenuButton`, `initPlugin` — регистрация в Lampa.

12. ОГРАНИЧЕНИЯ, ИЗВЕСТНЫЕ ПРОБЛЕМЫ И УСТРАНЕНИЕ ОШИБОК
--------------------------------------------------------------------------------
1) Ограничение по видеопотокам: Shikimori API не предоставляет видеофайлы. Для
   непосредственного воспроизведения видео в Lampa должны быть подключены
   стандартные плагины онлайн-просмотра или торрент-клиент (TorrServer).
2) Различия в разбивке сезонов между Shikimori и TMDB: На Shikimori каждый сезон
   аниме имеет собственный ID (например, 2-й и 3-й сезоны — отдельные карточки),
   тогда как в TMDB многосезонное аниме часто объединено в одну карточку сериала
   с годом выхода 1-го сезона. Именно поэтому плагин показывает список кандидатов
   TMDB через `Lampa.Select`, позволяя пользователю выбрать основную карточку сериала.
3) Ошибка HTTP 429 / Временная недоступность: Возникает при слишком частых запросах
   с одного IP. Плагин автоматически ограничивает частоту запросов и кэширует ответы.
   Если список не загрузился — нажмите кнопку «Повторить загрузку».

13. ОСНОВНЫЕ ИЗМЕНЕНИЯ ОТНОСИТЕЛЬНО СТАРОГО ПЛАГИНА
--------------------------------------------------------------------------------
- Полный переход на актуальный домен `https://shikimori.io` (вместо устаревшего
  `shikimori.one`, отдающего редирект 301) с автоматическим фоллбэком.
- Использование GraphQL API в качестве основного источника данных: исправлена
  проблема битых постеров (`missing_original.jpg` в старом REST API) и ускорена
  загрузка полной карточки в 4 раза.
- Отказ от устаревших (deprecated в новой Lampa) конструкторов `Lampa.InteractionMain`
  и `Lampa.InteractionCategory` в пользу совместимых компонентов на базе `Lampa.Scroll`,
  `Lampa.Controller` и `Lampa.Navigator`.
- Добавлена полноценная карточка аниме внутри Lampa (`shikimori_full`) со связанными
  релизами, хронологией франшизы, списком серий, тегами жанров и безопасным
  сопоставлением с TMDB.
